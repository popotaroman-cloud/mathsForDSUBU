Trace🔗ผลรวมของ diagonal entries ของ matrix ซึ่งเท่ากับผลรวมของ eigenvalues ทั้งหมด$\text{trace}(\mathbf{A}) = \sum_{i} a_{ii} = \sum_{i} \lambda_i$note_01_eigenvalues_diagonalization.md

Symmetric Matrix🔗matrix ที่ A เท่ากับ A transpose มี eigenvalues เป็นจำนวนจริงเสมอ และ eigenvectors ตั้งฉากกัน$\mathbf{A} = \mathbf{A}^T$note_01_eigenvalues_diagonalization.md

Spectral Decomposition🔗การเขียน matrix สมมาตรเป็นผลรวมของ rank-1 matrices ถ่วงน้ำหนักด้วย eigenvalue$\mathbf{A} = \sum_{i=1}^{n} \lambda_i \mathbf{q}_i\mathbf{q}_i^T$note_01_eigenvalues_diagonalization.md
Positive Definite Matrix🔗matrix ที่ x transpose A x มากกว่า 0 สำหรับทุก x ไม่เท่ากับ 0$\mathbf{x}^T\mathbf{A}\mathbf{x} > 0$note_01_eigenvalues_diagonalization.md

Gram Matrix🔗matrix ในรูป X transpose X ที่ใช้ eigh สำหรับหา eigenvectors ตั้งฉากกัน$\mathbf{X}^T\mathbf{X}$note_01_eigenvalues_diagonalization.md

Singular Value🔗ค่าบน diagonal ของ Sigma ใน SVD เรียงจากมากไปน้อย$\sigma_i = \sqrt{\lambda_i(\mathbf{A}^T\mathbf{A})}$note_02_svd_pca.md
