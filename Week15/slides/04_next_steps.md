## Slide 5 — Platform & Practice
**Key Message**: ความรู้เกิดจาก practice — platform เหล่านี้ให้ datasets จริงและ competition สำหรับฝึก

**Kaggle (kaggle.com):**
- Competitions: แข่งขัน ML กับคนทั่วโลก
- Datasets: ดาวน์โหลด dataset สำหรับ practice
- Notebooks: ดู solution ของคนอื่น — เรียนรู้ techniques ใหม่ๆ
- Courses: Free ML courses ของ Kaggle เอง

**GitHub:**
- Host Jupyter Notebooks
- สร้าง Data Science portfolio
- Contribute to open-source projects

**แนะนำให้ทำ หลังจบวิชา:**
```
1. ทำ Kaggle Titanic competition (บน test set ≥0.78) ← entry-level
2. ทำ Housing Prices competition (บน Ames dataset)
3. เขียน blog post อธิบาย 1 analysis ที่ทำ ← สร้าง portfolio
4. สร้าง GitHub repo ที่ใส่ Final Project
```

## Slide 9 — Final Message
**สิ่งที่ต้องจำจากวิชานี้ (3 ข้อ)**

```
1. "Always check Test Error, not Training Error"
   → ไม่มีประโยชน์ถ้า model แม่นบน training แต่ fail จริง

2. "Start with simple models"  
   → Linear Regression ที่ work ดีกว่า Deep Learning ที่ overfit
   → เพิ่ม complexity เมื่อมีเหตุผลเท่านั้น

3. "Math is the why, Code is the how"
   → เข้าใจสูตร → เขียน code ได้อย่างถูกต้อง
   → Debugging ง่ายขึ้นมาก เมื่อรู้ math
```
